# Ink Craft

Swear an oath. Brew spells. Get trophies. A card game in the Ink series, sister to Ink Nine, Ink Rally, Ink of Arms and Ink Sky.

- `index.html` is the front page; the game is in `play/`.
- The lords, cards, recipes and rules are in `play/js/engine.js`.
- `CLAUDE.md` explains the project to Claude Code, and `CHANGELOG.md` lists what changed in each version.

To run it on your computer: open a terminal in this folder, run `python -m http.server 8030`, then visit http://localhost:8030
